# Expense Tracker (Java Console Application)

A simple console-based **Expense Tracker** written in Java to demonstrate :

- Object-Oriented Programming (OOP)
- Collections (`List`, `Map`)
- File I/O using `java.nio`
- Enums
- Input validation & exception handling

---

## 🚀 Features

- Add expenses (description, amount, date, category)
- View all expenses (auto-sorted by date)
- Category-wise summary
- Month-wise summary
- Delete expenses by ID
- Data persistence using **CSV file (expenses.csv)**

---

## 📌 Technologies Used
- Java 17+
- VS Code (optional)
- CSV for storage

---
